Check a certificate

Use the details printed on a certificate to confirm that the organization named on it issued it.

  1. Find the certificate ID printed on the certificate.
  2. Enter the ID, the name and the certificate type as they appear.
  3. Compare the result with the certificate you are checking.

The ID starts with the event code, for example CH26-.

Capital letters and extra spaces do not matter.
